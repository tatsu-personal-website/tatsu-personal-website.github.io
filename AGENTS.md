## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## This project

- Content is Org, not Markdown: `content/essays/*.org` and `content/pages/*.org`, loaded by `src/lib/org-loader.ts` and rendered by `src/lib/org.ts` (uniorg → rehype). See README.md for the authoring conventions the renderer supports.
- Keep `katex` pinned to the same version `rehype-katex` renders with; the stylesheet must match the renderer.
